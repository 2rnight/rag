
# SmartAssist Pro 智能助手平台 - 产品说明书 V3.2

## 1. 产品概述

SmartAssist Pro 是智远科技自主研发的企业级AI智能助手平台，基于大语言模型技术，为企业提供智能客服、知识管理、数据分析等一站式解决方案。

### 1.1 产品特点
- 支持多轮对话，上下文理解准确率达95%以上
- 支持中英日韩等12种语言
- 可对接企业内部知识库，实现精准问答
- 支持私有化部署，保障数据安全
- 提供完善的API接口，易于集成

### 1.2 适用场景
- 智能客服：自动回复客户咨询，降低80%人工客服压力
- 内部知识库：员工可随时查询公司制度、产品信息
- 数据分析：自然语言查询业务数据
- 文档摘要：自动总结会议纪要、研报等长文档
- 代码辅助：辅助开发人员编写和审查代码

### 3.2 配置文件说明
配置文件位于 /etc/smartassist/config.yaml

主要配置项：
- model_name: 使用的模型名称（默认: smartassist-7b）
- max_tokens: 最大生成长度（默认: 4096）
- temperature: 生成温度（默认: 0.7）
- knowledge_base_path: 知识库存储路径
- database_url: 数据库连接地址
- redis_url: Redis缓存地址
- log_level: 日志级别（INFO/DEBUG/ERROR）

## 4. API 接口文档

### 4.1 对话接口
- 接口地址: POST /api/v1/chat
- 请求参数:
  - message (string, 必填): 用户消息
  - session_id (string, 可选): 会话ID，用于多轮对话
  - knowledge_base (string, 可选): 指定知识库名称
  - temperature (float, 可选): 0-1之间
- 响应格式:
  - code: 状态码（200成功）
  - data.reply: AI回复内容
  - data.sources: 引用来源列表
  - data.confidence: 置信度分数

### 4.2 知识库管理接口
- 上传文档: POST /api/v1/knowledge/upload
- 删除文档: DELETE /api/v1/knowledge/{doc_id}
- 查询知识库列表: GET /api/v1/knowledge/list
- 支持格式: PDF, Word, TXT, Markdown, HTML, CSV

### 4.3 数据分析接口
- 接口地址: POST /api/v1/analytics
- 支持自然语言查询数据库
- 自动生成SQL并执行
- 返回结构化数据和可视化图表

## 5. 常见问题 (FAQ)

Q1: 如何提升回答准确率？
A1: 建议从以下方面优化：
1. 提供高质量的知识库文档
2. 调整 chunk_size 参数（建议500-1500）
3. 使用更大的模型（如smartassist-13b）
4. 定期更新知识库内容

Q2: 系统支持多少并发用户？
A2: 单节点推荐配置下可支持100并发用户。通过集群部署可水平扩展，最高支持10000+并发。

Q3: 数据安全如何保障？
A3: 系统采用以下安全措施：
- 所有数据传输使用TLS 1.3加密
- 知识库数据加密存储
- 支持RBAC权限控制
- 操作日志审计
- 支持完全私有化部署，数据不出企业内网

Q4: 如何处理模型幻觉问题？
A4: 系统内置多层防护：
- RAG检索增强，确保回答基于真实文档
- 置信度阈值过滤（默认0.7以下自动提示不确定）
- 支持配置"无法回答"的兜底策略
- 人工审核队列

Q5: 支持哪些模型？
A5: 当前支持：
- SmartAssist-7B（默认，适合大多数场景）
- SmartAssist-13B（复杂推理场景）
- SmartAssist-70B（最高精度）
- 兼容 OpenAI GPT-4 API
- 兼容 Claude API
- 支持自定义微调模型
