
# 智远科技 常见问题解答 (FAQ)

## 一、IT 相关问题

Q1: 如何连接公司WiFi？
A: 公司WiFi名称为"ZhiYuan-Office"，密码为"ZhiYuan@2024"。首次连接需要在IT自助平台注册设备MAC地址。访客WiFi名称为"ZhiYuan-Guest"，无需密码，限速10Mbps。

Q2: 忘记电脑密码怎么办？
A: 请联系IT服务台（内线: 8888），工作时间（9:00-18:00）可远程重置密码。非工作时间请发邮件至 it-help@zhiyuan.com，次日处理。

Q3: 如何申请软件安装？
A: 登录内部OA系统 → 服务申请 → IT服务 → 软件安装申请。填写软件名称、用途、是否正版等信息。审批流程：直属上级 → IT部门，通常1-2个工作日完成。

Q4: VPN如何使用？
A: 下载公司VPN客户端（内网下载地址: http://vpn.zhiyuan.internal）。
配置信息：
- 服务器地址: vpn.zhiyuan.com
- 端口: 443
- 认证方式: 企业邮箱账号 + 动态令牌
远程办公必须通过VPN访问内部系统。

Q5: 打印机无法连接？
A: 请按以下步骤排查：
1. 确认打印机电源开启，状态灯为绿色
2. 检查网络连接是否正常
3. 删除已有打印机驱动，重新安装
4. 各楼层打印机IP地址：
   - 1楼大厅: 192.168.1.101
   - 2楼研发: 192.168.1.102
   - 3楼市场: 192.168.1.103
   - 4楼行政: 192.168.1.104
5. 如仍无法解决，联系IT服务台

## 二、行政相关问题

Q6: 如何预订会议室？
A: 通过企业微信 → 工作台 → 会议室预订系统。
会议室列表：
- 101会议室（6人）：配备投影仪、白板
- 201会议室（12人）：配备大屏电视、视频会议设备
- 301培训室（50人）：配备音响系统、直播设备
- 401贵宾室（8人）：配备茶水服务
预订规则：最早可提前7天预订，最晚提前30分钟取消。超过预定时间15分钟未使用自动释放。

Q7: 快递如何收发？
A: 
- 收件：所有快递统一送至1楼前台，到件后前台会通过企业微信通知
- 寄件：填写寄件单放置前台寄件区，每日16:00统一寄出
- 公司合作快递：顺丰、京东，享受协议价
- 私人快递费用自理

Q8: 办公用品如何领取？
A: 每月1日和15日为办公用品领取日。在OA系统提交领用申请，审批通过后到4楼行政部领取。常备物品：笔、本、文件夹、订书机等。特殊物品需提前5个工作日申请。

Q9: 公司班车路线？
A: 公司提供3条班车路线：
- A线：地铁10号线知春路站 → 公司（发车时间：8:00, 8:30）
- B线：地铁13号线西二旗站 → 公司（发车时间：8:00, 8:30）
- C线：地铁4号线中关村站 → 公司（发车时间：8:15, 8:45）
- 下班班车统一18:30从公司出发
- 乘车需刷工牌

Q10: 报销流程是怎样的？
A: 
1. 在OA系统提交报销申请
2. 上传发票照片（需清晰可辨）
3. 审批流程：直属上级 → 财务部
4. 报销金额限制：
   - 1000元以下：部门经理审批
   - 1000-5000元：总监审批
   - 5000元以上：VP审批
5. 审批通过后，下月15日随工资发放
6. 发票要求：必须为增值税普通发票或专用发票，抬头为公司全称

## 三、人事相关问题

Q11: 如何申请调岗？
A: 内部转岗流程：
1. 与现部门负责人沟通
2. 联系目标部门了解岗位需求
3. 在OA系统提交转岗申请
4. 双方部门负责人 + HR审批
5. 审批通过后确定交接时间（通常2-4周）
6. 转岗后岗位等级保持不变

Q12: 绩效考核周期和标准？
A: 
- 考核周期：每季度一次
- 考核等级：S(卓越10%)、A(优秀20%)、B+(良好30%)、B(合格30%)、C(待改进10%)
- 考核维度：
  - 工作业绩（60%）
  - 能力提升（20%）
  - 团队协作（20%）
- 结果应用：
  - S级：绩效奖金30%，优先晋升
  - A级：绩效奖金20%
  - B+级：绩效奖金10%
  - B级：绩效奖金0%
  - C级：进入绩效改进计划（PIP）

Q13: 社保公积金缴纳基数？
A: 
- 社保缴纳基数：以上年度月平均工资为基数
- 公积金缴纳比例：公司12% + 个人12%
- 缴纳基数上限：当地社平工资3倍
- 缴纳基数下限：当地最低工资标准
- 每年7月调整基数

Q14: 如何开具在职证明/收入证明？
A: 在OA系统 → 人事服务 → 证明开具。选择证明类型，填写用途。HR在3个工作日内出具，到人力资源部领取（盖公章）。电子版可直接下载。
